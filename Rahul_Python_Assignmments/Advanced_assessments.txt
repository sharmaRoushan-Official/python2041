21. Write a Python program to calculate **discount** based on purchase amount:

    * > 1000 → 20% discount
    * 500–1000 → 10% discount
    * <500 → No discount
	
val =  int(input("Enter price:"))
if val>1000:
    calval=val*20/100
    print(f"Discount 20% applicable on {val} so discount would be:{calval}")
elif val>500 and val<=1000:
    calval=val*10/100
    print(f"Discount 10% applicable on {val} so discount would be:{calval}")
elif val<=500:
    print(f"No discount on {val}")
else:
    print("Enter valid amount")
